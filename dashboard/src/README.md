# Task API Project

## 📌 Overview
This is a Flask-based Task Management API that allows users to create, read, update, and delete tasks. It also supports user authentication and role-based access control.

## ⚙️ Technologies Used
- Python (Flask)
- MySQL
- SQLAlchemy (if you're using it)
- Postman (for testing API)
